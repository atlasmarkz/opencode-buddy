# @mark_future_ai/opencode-buddy v1.1.2

## Floating pet

- New **48×48 pixel-art** built-in pets: duck, cat, dragon, axolotl, robot, ghost.
- Smaller eyes, cleaner outlines, five expressions, and per-state animations.
- Custom **Codex pet packs** still import directly from `~/.codex/pets/`.

## Hide / restore

- Hiding the pet from the right-click menu now tells you how to bring it back.
- New composer slash command: **`/buddy-pet`** toggles the floating pet.
- The command palette entry **Toggle floating pet** still works.

## Install

Requires OpenCode 2.2.6+.

```bash
npm install -g @mark_future_ai/opencode-buddy
```

Restart OpenCode Desktop after upgrading.
